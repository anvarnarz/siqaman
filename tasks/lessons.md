# Lessons

- **Several design systems can share a name.** When asked for a named design system, list every match and compare their palettes before building. For Ertaga Kech, the brand accent is green (#3AD754).
- **Don't assume a theme default from the design system.** Ask, or offer both: the user wanted light mode by default even though the system is dark-first.
- **Archive errors here are Siqaman bug reports.** Reproduce with the bundled `/Applications/Siqaman.app/Contents/MacOS/7zz` and fix the app; don't hand out CLI workarounds.
