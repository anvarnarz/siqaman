# Lessons

- **Several design systems can share a name.** When asked for a named design system, list every match and compare their palettes before building. "Ertaga Kech" exists as a copper copy and as the green (#3AD754) brand system; the green one is canonical.
- **Don't assume a theme default from the design system.** Ask, or offer both: the user wanted light mode by default even though the system is dark-first.
